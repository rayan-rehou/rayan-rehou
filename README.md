# Hi, I'm Rayan Rehou👋

**Computer Engineering Student @ University of Ottawa 🇨🇦**

I'm a Computer Engineering student passionate about technology, problem-solving, and understanding how software and hardware systems work together.

I’m especially interested in embedded systems, IoT, and computer vision, and in how to keep connected devices secure. I like learning by building: right now that means an ESP32 temperature monitor with a live web dashboard and a hand-gesture controller that runs on a webcam.


## 🔍 Areas of Interest

- 🔌 **Embedded Systems & IoT** — Exploring microcontrollers, sensor integration, and connected devices through hands-on Arduino and ESP32 projects.
- 👁️ **Computer Vision & AI** — Developing real-time applications using webcam-based hand tracking, gesture recognition, and machine learning.
- 🔐 **IoT & Systems Security** — Learning about network security, device authentication, and secure communication in connected systems.
